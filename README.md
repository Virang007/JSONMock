### 🌟 About Me & My Work

I am an independent software developer passionate about developer experience, API tooling, and open-source software. 

Your support helps me maintain, host, and improve my open-source projects, including:

* ⚡ **[JSONMock](https://github.com/Virang007/JSONMock)** — A lightweight, reliable mock REST API service with 6 core resources (`/posts`, `/comments`, `/albums`, `/photos`, `/todos`, `/users`).
